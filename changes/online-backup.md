### Added

- Options > Save data > Back up online: saves an encrypted copy of everything the game keeps in
  this browser on five free servers (Nostr relays), found again by a 10-character backup code
  shown once, with Copy and Share. The first time, a short note explains what the servers see
  (an anonymous ID and when you backed up, nothing personal) and that free servers may lose it,
  so keep a backup file too. Backing up again replaces the online copy. Dev mode's settings stay
  off the online copy.
- Options > Save data > Restore from code: type the backup code (as forgivingly as a save code)
  to bring the data back on any device, through the same checks and REPLACE ALL DATA ON THIS
  DEVICE? question as Import backup. Offline, both rows say they need an internet connection;
  every failure is said and changes nothing. The downloaded offline copy has neither row.
