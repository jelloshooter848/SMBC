### Added

- Options > Save data > Back up online: saves an encrypted copy of everything the game keeps in
  this browser (saves, settings, custom levels, progress, the names of the packs turned on; not
  the pack files) on five free servers (Nostr relays), found again by a 12-character backup code
  shown after the first backup, with Copy and Share. The first time, a short note explains what
  the servers see (an anonymous ID and when you backed up, nothing personal) and that free
  servers may lose it, so keep a backup file too. Backing up again replaces the online copy. Dev
  mode's fields stay off it, in the settings and in Campaign files.
- Options > Save data > Restore from code: type the backup code (as forgivingly as a save code)
  to bring the data back on any device, through the same checks and REPLACE ALL DATA ON THIS
  DEVICE? question as Import backup. Offline, the online rows say they need an internet
  connection; every failure is said and changes nothing. The downloaded offline copy has none
  of them.
- Options > Save data > Show my code and Delete online copy, once this device has a backup code.
  Delete online copy empties the copy on the servers and asks them to delete it, keeping the
  code; Erase all data asks ALSO DELETE YOUR ONLINE BACKUP? first.
