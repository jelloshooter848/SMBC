# Local asset packs

Drop asset packs in this folder for local development. Each pack is a folder with a
`manifest.json` (see `docs/asset-packs.md`). Everything here except this README is gitignored,
so sprite rips or other material you are not allowed to redistribute never enter the repository.

List packs in `user-packs/index.json`:

```json
{ "packs": ["my-pack"] }
```
