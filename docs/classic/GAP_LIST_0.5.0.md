# Classic mode gap list for 0.5.0

What still differs between **Classic mode** (title > CLASSIC) and the original **Super Mario Bros. Crossover
3.1.21**, the version in the public MIT source at `JayPavlina/super-mario-bros-crossover`. Its README says it is the
final 3.1.21 build, and `src/com/smbc/data/Versions.as:63` returns "3.1.21". This list is for the owner to approve as
the 0.5.0 scope. Nothing in it is built yet.

## Summary

|       | P0 (must) | P1 (should) | P2 (polish) | X (different by rule) | Total |
| ----- | --------- | ----------- | ----------- | --------------------- | ----- |
| Items | 23        | 34          | 37          | 21                    | 115   |

**Top 10** (all confirmed unless marked):

1. **G-001/G-002 The Lost Levels run straight on from 1-1 to D-4.** We follow the NES rules instead: World 9 needs a
   run without warps, 9-4 ends the run, and A-D are never reached in Classic.
2. **G-010 Each level built for the hero playing it.** The original has extra and hidden pieces for heroes with
   short reach (Link, Samus, Simon, Mega Man, Bill, Ryu, Quick Man). Our converter drops them all. Example: 1-1's
   lift by the flagpole.
3. **G-011/G-012 Bad-swimmer pieces in the Lost Levels and the extra Bowser pieces for Simon and Ryu.** Same system.
4. **G-013 Water levels pull Mario and Luigi into the pits** (PitVacuum).
5. **G-020 The Super Mario Bros. Special map set**, 32 levels, offered on New Game from the start. It brings
   **G-021** five enemies and **G-022** three items we lack.
6. **G-060 Per-hero music sets.** By default the original plays each hero's own game's music. Ours are our own
   compositions; several hero tunes already exist in the campaign.
7. **G-061 The character select is silent**; the original has select music.
8. **G-070 Hero actions with no sound** (Mega Man landing and teleport, Samus landing, morph ball and Screw Attack,
   Bill landing).
9. **G-100/G-101/G-102 Gate the campaign behind "Chapter 1 coming soon!"** outside dev mode (Start game and
   `#save=` links), keeping every campaign save.
10. **G-103-G-110 Release and branding for 0.5.0.** Drop PRE-RELEASE and CHAPTER 1 from the title, set version
    0.5.0, rewrite ROADMAP and README, rename the zip and the repo, and keep the old `/SMBC/` address working.

**Owner decisions this list needs** (each item below says which):

- **D1. Special map set (G-020):** P0 as the original offers it, or move it to a later release? Its data can come
  through the same converter that built our SMB and Lost Levels maps (`tools/levelgen/convert-smbc.mjs:1-6` reads
  the original's MIT level XML), so no new data source is needed. If it moves out, G-021/G-022 drop to P1 with Map
  Difficulty.
- **D2. Per-hero music (G-060):** the owner parked _per-skin_ music (`FOLLOW_UPS_PROPOSAL.md:12-13`). This is the
  original's _default_ behaviour (each hero's own game's music), so it is listed P0. One set of our own songs per
  hero is needed; types a hero has no song for fall back to the SMB set.
- **D3. Lost Levels lock and the SMB ending (G-003, G-004):** the original offers all sets from the start and goes
  back to the title after the credits. Ours opens the Lost Levels only after 8-4 and then goes straight on (owner
  decision, 0.4.56).
- **D4. WORLD card (G-090):** the original moves on by itself. Keep that as a written exception to "text never
  moves on by itself", or make it wait for a press?
- **D5. Release names (G-108, G-109):** the new zip name and the new repo name.

**Corrections to earlier docs:**

- `FOLLOW_UPS_PROPOSAL.md` FU-7e calls the original's **Classic Samus** and **Classic Simon** cheats no-ops. They
  are not: `data/Cheats.as:327,337` set `Simon.classicMode` and `Samus.classicMode`, and both heroes read the flag
  (see G-040).
- **World 9:** in 3.1.21, 8-4 is an ordinary castle. Our "no warps" rule comes from the NES game, not from SMBC.

**Not counted (already in flight):**

- The exact original select screen: two rows (Mario, Luigi, Link, Samus, Simon / Mega Man, Bass, Bill, Ryu, Sophia,
  Random).
- Pit, Proto Man and Peach moved under Samus, Mega Man and Luigi as looks.
- An "Expansion heroes" option, off by default, for Vic Viper, the Warriors of Light, Arthur and Yoshi. This matches
  3.1.21, where Vic Viper, the Warriors and Proto Man are commented out of `data/CharacterInfo.as:46-47,56-59`.
- "Special = random look and start".
- The phone first-tap bug on text cards.

**How to read the table rows.** Original paths are relative to `src/com/smbc/` in the original repo unless they
start with `assets/` or `com/explodingRabbit/` (that is, `src/com/explodingRabbit/`). Many original `.as` files use
old-Mac CR line endings: a cited line number is the editor line after `tr '\r' '\n'`. Ours are relative to this
repo, at `54560bf`.

- **Priority:** P0 = needed for a true remake in 0.5.0; P1 = should have; P2 = polish; X = intentionally different
  under project rules.
- **Size:** S, M or L.
- **Status:** **C** = confirmed in both codebases; **U** = unverified.
